# Loafology Website Clone

## 📌 Overview
This project is a **front-end clone** of the [Loafology Bakery & Cafe] website, built as **Task 1** of my Web Development Internship at ELITE.Org.

> ⚠️ **Disclaimer:** This is a practice/educational clone created to improve my HTML and CSS skills. All code was written independently by me. This project is **not affiliated with, endorsed by, or copied directly from** the original Loafology business, and is intended for portfolio/learning purposes only, with no commercial intent.

## 🎯 Goal
To recreate the layout, structure, and responsive behavior of a real-world bakery/cafe website as a hands-on front-end development exercise.

## 🛠️ Built With
- HTML5
- CSS3 (Flexbox, Grid, responsive media queries)
- Font Awesome (icons)
- Pure CSS slider (radio-input driven)

## ✨ Features
- Fully **responsive design** — adapts across desktop, tablet, and mobile
- Sticky, structured **navigation bar** with logo, search, account, and cart icons
- **Auto-rotating hero image slider** with dot and arrow navigation, built entirely in CSS
- Multiple linked pages, sharing a consistent header and footer:
  - **Home** — hero slider, intro text, branch showcase
  - **About** — brand philosophy section
  - **Locations** — branch selector grid
  - **Order Now** — same branch selector grid, for ordering
  - **Contact** — contact form with locations footer
